The Naked Invaders

A game of Space Invaders that wears its source code on the outside. Every rule the game runs is listed on the right — as the actual code. Untick a line and the game truly stops running it. No collisions? No score? No edge to turn the fleet around? Find out what a game is made of by taking it apart while it runs.
