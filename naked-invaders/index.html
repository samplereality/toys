The Naked Invaders

A game of Space Invaders that wears its source code on the outside. Every rule the game runs is listed on the right — as the actual code. Click a line to switch it off and the game truly stops running it. No collisions? No score? No edge to turn the fleet around? Remove a boundary and nothing disappears — it just keeps going, out of the game and onto the page.
