# toys
Assortment of tools, toys, and experiments

- [**The Atlas of America**](american-atlas/) — a satirical interactive map of the world in which every body of water is named America and every national park is Trump National Park. Courtesy of the Bureau of Patriotic Nomenclature. Live at [americanatlas.world](https://americanatlas.world/).

Each project lives on its own branch and is served as a Vercel branch
deployment (the branch's `vercel.json` redirects the deployment root to
the project's folder).
