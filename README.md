# toys
Assortment of tools, toys, and experiments

- [**American Atlas**](american-atlas/) — a satirical interactive map of North America in which every body of water is named America and every national park is Trump National Park. Courtesy of the Bureau of Patriotic Nomenclature.

Each project lives on its own branch and is served as a Vercel branch
deployment (the branch's `vercel.json` redirects the deployment root to
the project's folder).
